# Cow training artwork

14 individual assets: one transparent PNG cover and one opaque WebP scene for each completed single-lesson template. Each file is smaller than 500,000 bytes.

Generated with the built-in image generation tool using the established soft hand-drawn watercolor/pencil direction. No embedded captions; UI captions remain application text. Resolve `rasterPath` against the repository data base URL.

Artwork is illustrative and visually inspected, not expert-reviewed instruction. Existing lessons, safety notes and evidence metadata are unchanged. Flutter rendering has not been tested.

See [PROMPTS.md](PROMPTS.md) for the final prompt set and [VALIDATION.md](VALIDATION.md) for inventory checks.

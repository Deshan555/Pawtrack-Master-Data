# Dog hand-drawn training image expansion

Adds 65 separately generated illustrations, one transparent PNG cover and four WebP lessons per template. Dog Sit remains unchanged from the pilot. No collage extraction or cropping. All final files are strictly below 500,000 bytes.

## Validation and limits

Built-in ChatGPT image generation only; no paid external API. Covers are RGBA PNG with verified 0–255 alpha; proportional resize preserves transparency. Lessons use WebP quality 80–95, method 6, with source dimensions retained. This encoding is lossy. Every file decodes successfully. Dimensions, byte sizes and SHA-256 hashes are recorded in dog/index.json. Incorrect collar-attached long lines were regenerated using a harness. Existing non-media training metadata remains unchanged; modified JSON manifest checksums and sizes are validated.

Visual checks cover behavior, obvious anatomy defects, complete dog framing, text, unsafe handling and lead attachment. These are cartoons and are not qualified expert-reviewed technique diagrams. Still images cannot establish cue timing, willingness over time, reliability or practice on another day. Trainer hair, props and settings vary slightly. Lesson text supplies the full instructions. This repository has no Flutter application source; device rendering is untested. No master merge or release publication.

# Cat training artwork

75 individual images cover all 15 Cat training templates: one transparent PNG cover and four opaque WebP lesson scenes per template. Every file is smaller than 500,000 bytes.

Generated with the built-in image generation tool. The visual direction is soft hand-drawn watercolor/pencil art with a consistent ginger tabby, cream muzzle and chest, green eyes, sage clothing and pastel lavender accents. No embedded captions; render captions as application text.

Resolve each `rasterPath` against the repository data base URL. The Cat asset index contains dimensions, byte counts, SHA-256 checksums and alt text. Cat template `media` links the cover and each lesson.

See [PROMPTS.md](PROMPTS.md) for the final prompt set and [VALIDATION.md](VALIDATION.md) for the inventory and checks. Artwork is illustrative and has been visually inspected; it is not expert-reviewed veterinary or training instruction. Existing training content, references, evidence fields and review statuses are unchanged.
